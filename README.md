# VoxelChat

The current app in this repo is **Smol**, a character chat powered by
SmolLM2-1.7B-Instruct running locally on **node-llama.cpp**.

```bash
npm i
npm start     # → http://localhost:5173
```

➡️ See [`smol/README.md`](smol/README.md) for architecture, the local API and settings.

The older VoxelChat pages at the repo root are unmaintained placeholders and are not
used by the Smol app.
